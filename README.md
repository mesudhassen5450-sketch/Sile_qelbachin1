## 🌟 About

**ስለ ቀልባችን (About Our Hearts)** is a comprehensive Islamic educational platform designed specifically for Ethiopian youth navigating the challenges of modern life. In this era of digital distractions and spiritual trials, our platform provides authentic Islamic teachings rooted in the Qur'an and Hadith, helping young Muslims strengthen their faith and purify their hearts.

### 🎯 Mission

በዚህ የፈተናና የቴክኖሎጂ ዘመን ከቁርኣንና ከሐዲሥ ቀልባችንን የምናክምበትን ጥበብ በጋራ የምንፈልግበትና ለወጣቱ ትውልድ በራሱ ቋንቋ የሕይወት መፍትሔዎችን የምናመላክትበት የእስልምና ትምህርታዊ መድረክ።

*A platform where we collectively seek the wisdom to heal our hearts from the Qur'an and Hadith in this age of trials and technology, delivering life solutions to the youth generation in their own language.*

### 🌍 Why This Platform?

- **🇪🇹 Ethiopian Context:** Content in Amharic, Arabic, and English
- **📱 Digital Native:** Mobile-first, modern UI/UX
- **🎓 Authentic Knowledge:** Teachings from qualified scholars
- **❤️ Heart Purification:** Focus on spiritual wellness
- **🎧 Audio-First:** Extensive lecture library for on-the-go learning
- **📚 Kitab Studies:** Structured Islamic book series with detailed lessons

## 🚀 Getting Started

### Prerequisites

- **Node.js** 20+ ([Download](https://nodejs.org/))
- **npm** or **bun** package manager
- **Git** ([Download](https://git-scm.com/))

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/sle-qelbachin-website.git
cd sle-qelbachin-website

# Install dependencies
npm install
# or with bun
bun install

# Run development server
npm run dev
# or with bun
bun dev
```

### Access the Application

- **Local Development:** [http://localhost:3000](http://localhost:3000)
- **Production:** [https://sle_qelbachin1.netlify.app](https://sle_qelbachin1.netlify.app)

### Build for Production

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run start
```

## 🌐 Deployment

### Deploying to Netlify

1. **Connect Repository**
   - Sign in to [Netlify](https://netlify.com)
   - Click "New site from Git"
   - Choose your repository

2. **Configure Build Settings**
   ```
   Build command: npm run build
   Publish directory: out
   Node version: 20
   ```

3. **Environment Variables** (if needed)
   ```
   NEXT_PUBLIC_SITE_URL=https://sle_qelbachin1.netlify.app
   ```

4. **Deploy**
   - Click "Deploy site"
   - Site will be live at your Netlify subdomain

### Custom Domain Setup

1. Go to **Domain settings** in Netlify
2. Add custom domain: `sle_qelbachin1.netlify.app`
3. Configure DNS settings
4. Enable HTTPS (automatic with Netlify)
