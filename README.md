## 📋 Quick Overview

Sle Qelbachin is a comprehensive Islamic educational platform that provides access to:

- **📖 Islamic Kitab Collections** – Curated books with organized audio lectures
- **🎧 Audio Ders** – Listen to Islamic lessons and teachings
- **🎙️ Muhadara** – Islamic lectures and speeches
- **💭 Islamic Reminders** – Daily reflections and beneficial reminders
- **📿 Qur'an & Hadith** – Sacred texts and prophetic traditions
- **👥 Sahabah Content** – Stories and lessons from the Prophet's companions
- **🎥 Educational Videos** – Visual Islamic learning resources
- **🤖 AI-Assisted Navigation** – Intelligent website navigation helper
- **🌍 Multilingual Interface** – Available in Amharic, Arabic, and English

---

## ✨ Key Features

### 📖 Kitab Library

Each Kitab (book) contains multiple organized audio lectures:

```text
📚 ONE KITAB
      ↓
🎧 MANY AUDIO DERS (Lectures)
      ↓
📄 PDF DOCUMENTS (Where Available)
      ↓
🎵 READ / LISTEN / LEARN
```

**Features:**
- Comprehensive kitab collections with detailed metadata
- Multiple audio ders per kitab with speaker information
- PDF document viewing where available
- Organized by category and topic
- Search and browse functionality

### 🎧 Audio Experience

- **Global Audio Player** – Play audio across all pages
- **Playback Controls** – Play, pause, seek, volume control
- **Progress Tracking** – Remember where you left off
- **Playlist Management** – Queue multiple ders
- **Mobile-Optimized** – Seamless listening on any device

### 🎙️ Muhadara (Lectures)

- Browse muhadara collections
- Random muhadara feature for discovery
- Previous lectures history
- Integrated audio player
- Speaker information and metadata

### 🎥 Video Library

- Video content cards with thumbnails
- Embedded video playback
- External video source integration
- Categorized video collections

### 💭 Islamic Content

- **Reminders** – Daily Islamic reflections
- **Qur'an** – Verses and tafsir
- **Hadith** – Prophetic traditions
- **Sahabah** – Companion biographies
- **Lessons** – Educational Islamic content

### 🤖 AI Knowledge Assistant

An intelligent navigation assistant that helps visitors:

```text
👤 Visitor Question
        ↓
🔍 Content Matching
        ↓
📚 Website Content
        ↓
🎯 Navigation / Audio / Page Action
```

**Assistant Capabilities:**
- Find specific kitab by name or topic
- Locate audio ders and lectures
- Navigate to muhadara collections
- Discover videos and reminders
- Access Qur'an and Hadith content
- Get verified social media links
- Website navigation guidance

The assistant uses natural language processing to match visitor questions with actual website content, providing accurate navigation and content recommendations.

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager
- Git

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/mesudhassen5450-sketch/Sile_qelbachin1.git
cd Sile_qelbachin1
```

2. **Install dependencies**

```bash
npm install
```

3. **Set up environment variables**

Create a `.env.local` file in the root directory:

```env
GROK_API_KEY=your_grok_api_key_here
```

> 💡 Get your Grok API key from [console.x.ai](https://console.x.ai/)

4. **Run the development server**

```bash
npm run dev
```

5. **Open your browser**

Navigate to [http://localhost:3000](http://localhost:3000)

## 🎵 Media Architecture

The platform manages Islamic educational content through a structured media system:

```text
📚 Kitab Metadata (JSON)
         ↓
🎧 Ders References
         ↓
🌐 CDN / Media URLs
         ↓
🎵 Audio Player
```

**Media Strategy:**

- **Audio Files:** Served via CDN for optimal performance
- **PDF Documents:** Linked for download or viewing
- **Video Content:** Embedded or externally hosted
- **Images:** Optimized and served through Next.js Image optimization

> 📦 Large media archives are managed separately from the source repository for optimal Git performance. Deployment and media handling instructions are documented in `DEPLOYMENT.md`.
