# Sile Qelbachin Admin

Admin CMS UI based on the AdminCN Next.js template, rebranded for **ስለ ቀልባችን / Sile Qelbachin**.

See **[ADMIN.md](./ADMIN.md)** for architecture and local run instructions.

## Quick start

```bash
npm install
npm run dev -- --port 3001
```

- Dashboard: http://localhost:3001/dashboard  
- Gateway (future): https://admin.sileqelbachin1.com
